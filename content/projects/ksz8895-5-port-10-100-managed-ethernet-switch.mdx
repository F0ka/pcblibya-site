## KSZ8895 5-Port 10/100 Managed Ethernet Switch

A fully integrated 5-port 10/100 Mbps managed Ethernet switch based on the Micrel KSZ8895RQXC in a compact 100×60mm 4-layer PCB.

### Features

- 5× 10/100 Mbps RJ45 ports with integrated magnetics (Hanrun HR911105A)
- KSZ8895RQXC managed switch IC (128-pin QFP) — supports VLAN, QoS, IGMP snooping
- Single 3.3V supply via AP1117-33 LDO (5V barrel jack input)
- 25 MHz crystal oscillator
- Reverse polarity protection (PMOS + Schottky)
- 4-layer stackup with solid GND pours on all layers
- 4× M3 mounting holes
- JLCPCB-compatible design rules (0.15mm clearance, 0.2mm tracks)

### Pin Headers

| Header | Function |
|--------|----------|
| J7 | UART/SMI access |
| J8 | SPI/Management interface |
| SW1 | Reset button |

### Manufacturing

Designed for JLCPCB 4-layer service. All design rules exceed JLCPCB minimums:
- Clearance: 0.15mm (JLCPCB min: 0.09mm)
- Track width: 0.2mm (JLCPCB min: 0.09mm)
- Via: 0.6mm/0.3mm (JLCPCB min: 0.25mm/0.15mm)
